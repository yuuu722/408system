# 学习任务讲解与例题作答（2026.11.09.3）

## 页面宽度

测评与学情、薄弱点复习恢复普通页面共用的1280px最大主区域宽度与响应式内边距，与学习任务等页面一致。移除此前两类页面的全宽覆盖规则。

## 知识复习

主区域直接显示当前学习单元的连贯讲解，按概念/适用条件、原理/逻辑和易混点组织完整段落；不再默认展开上传资料的分块。引用和原文收进教材来源，点击才打开原文。

首次进入可见的知识复习区域时加载保存的讲解；没有可用版本才调用已有RAG服务整理，语气采用轻松鼓励风格。仅保存通过原文核验、具备可访问教材来源的讲解。按用户、知识点、资料版本保存，后续打开复用；引用文档或分类变化时失效，生成期间教材变化也不保存旧结果。缓存不存在或模型失败明确提示重试，不将原文摘录伪装成完整讲解。此处“完整”为本单元已获支持的内容，不表示替代整本教材或凭空补齐缺失知识。

## 例题

学习任务与知识点面板使用同一作答组件。先选选项/暂时不会，再提交正式测评记录；未提交不显示答案解析。判分复用已有资料答案判分流程，错误同步进入有效学习事件、薄弱点与错题记录。提交后立刻显示原文解析，后台再整理按条件→依据→推导→结论的老师详解，语音可朗读。模型失败不影响已保存成绩和原文解析；详解不重新判分。

未完成的例题可恢复，同日资源不会因待提交状态突然换题；可以重新作答，同题仍按同一题族最近有效结果统计，不增加独立题组数量。看过解析后的再答不代替新题复测。取消“我已理解”作为例题完成依据，旧确认记录保留但不会伪造测评结果。完成例题仅表示完成这个环节，不等于掌握整章。

接口按用户隔离尝试与详解，提交前不能请求老师解析。独立练习及新题检查继续与例题分离。

## 验证与部署

迁移28只新增讲解缓存和例题尝试关联表，不重新解析资料，不删除历史记录。更新全部服务至2026.11.09.3。

隔离PostgreSQL/HTTP回归覆盖例题提交与错误事件、禁止手动伪造例题完成、解析权限、模型失败保留判分、讲解缓存复用/权限/来源变化失效及生成期间变更拒绝。浏览器合成接口验证普通页面宽度相同、正文不是分块、缓存复用、先答后讲、异常状态和移动布局；未对用户本机模型及全量教材内容作验收。
