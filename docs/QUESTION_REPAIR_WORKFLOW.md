# 概念反转防护与题库修复（2026.11.06.3）

## 这次解决的代码问题

- “多次性却必须一次性全部装入”“虚拟存储器的驻留性特征允许换出”等已知概念反转增加拒绝检查，允许“不需要一次性装入”“打破传统驻留性”等正确否定表达；事实目录和摘录回退也不使用这些已识别的错误句。提示词强调核对肯定否定和特征归属。这是少量高风险断言的防护，不是所有教材知识的正确性证明，真实小模型仍需本机验收。
- 编号单选题支持题号与正文分行、全角数字、数字和标点间空格、字母选项单独成行或以空格分隔、括号答案标签；仍不从缺失选项中编造选择题。显式多个答案不能偷偷取第一个当单选答案。
- 问题图片按结构化文本偏移关联，避免每道题都附上同页全部图片。存在可定位OCR置信度块时，只阻断重叠题目行；未知/结构性页面失败仍阻断整页。答案文件相同地按可定位行检查，原文引用保留全角原貌，仅题号标识规范化。
- 复用现有解析的“整理”操作保护已发布、人工编辑及已有关联答案证据的题目：即使新抽题结果为零，也不删除或覆盖这些成果。此保护针对当前活动解析的重新抽题，不等于更换源文件时永远保留陈旧题目。

## 本机使题目进入练习的顺序

1. 拉取并启动2026.11.06.3，先不运行全库重新OCR。
2. 管理员进入公共资料管理，核对题目文件用途为“题库”或“两者”。只有“知识库”用途不会抽题，这是有意分离教材证据与题库。
3. 点击“整理本库已有资料”，复用已存解析。展开“逐文件抽题结果”，看哪些被用途跳过、哪些确实识别为零，而不是把文档就绪当成题库已发布。
4. 题目和答案在不同文件时，先在资料页预览同版本、章节的答案配对；无唯一匹配时指定文件与章节，不能只按重复题号猜配。
5. 进入“题库与课程审核”：计数区区分候选题、已可练习、待审核、待修复与缺答案。修复题干/选项/图片、选择正确知识点，核对原文答案。只有无解析问题且具备可靠答案与知识点的题目能勾选。
6. 勾选已逐题核对的候选，点击“发布选中且已核对的题目”，确认后逐项执行现有带版本检查的保存接口。失败单独显示，不伪报全部成功。学生只看到已可用公共题目，提交有效作答后才形成学情。

不直接在数据库把status统一改成ready，不自动发布模型猜测的答案，不插入演示题掩盖题库为空。缺图、主观/多选题或文字本身缺失的资料仍需修复；本轮单选抽取改进不等于已实现所有题型自动判分。若保存的原始解析已经丢了内容，只整理不能恢复，需对相应文件重新处理而不是反复全库重跑。

新代码不会在云端自动修改你电脑中的资料或发布题目；以上操作需在实际部署执行。源码更新和数据处理结果是两回事。
