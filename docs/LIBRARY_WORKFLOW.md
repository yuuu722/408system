# 公共教材、题库与个人资料的使用流程

## 资料组织

公共库由管理员维护；个人库归成员自己维护。一个文件只上传一次，在资料页选定学科、类型与用途。

| 类型 | 推荐用途 | 在问答中的角色 |
|---|---|---|
| 教材、课本 | 知识库；需要抽取课后题时选两者 | 首选定义、原理、条件 |
| 讲义、笔记 | 知识库 | 教材后的补充 |
| 真题、习题、模拟卷 | 题库 | 候选题，不把选项当结论 |
| 答案解析 | 两者 | 补充解题依据与关联答案 |
| 考纲 | 知识库 | 学习范围、目录；不作详细结论证据 |

自动分类是文件名/目录规则建议，不是内容识别或准确性认证。未能可靠识别时保留待分类，不能随意归为教材或真题。已有已确认分类保留。

资料页可按学科、类型筛选，选择文件后批量确认。仅维护者看到待确认资料；学生列表只展示已确认分类。`整理本库已有资料`复用已保存解析，仅对题库/两者用途生成待审核候选；不重传、不重新OCR。文件名没有学科信息的跨科文件可选综合。

旧导入清单中的类型可编辑；新导入脚本区分真题、习题、模拟卷，先按文件名再回退父目录规则。脚本不代表题目已审核发布。

## 题目、答案和解析

结构化题库与文档片段分开保存，以文件/页码/知识点关联。当前规则自动抽取编号单选题，支持括号编号、全角选项和跨页内容，不声称完整支持任意数学排版、证明题或图表恢复。解析异常、缺图、缺选项的候选不得自动发布。

管理员在题库与课程审核页核对题干、选项、答案和知识点。另一文件中的解析可在编辑题目时通过“关联另一文件的参考答案与解析”指定文件、页码、逐字原文；原文校验后仍为待审核。不能仅按相同题号跨书自动配对。原文存在不等于管理员已经核实解析与题目匹配。

问答末尾推荐最多3道同知识点、已发布且可用的题目，优先真题。没有合格题目时不伪造题目。相关推荐用于新回答，不回写旧聊天历史。

## 检索和回答

1. 识别题意、知识点；图片先转写，学生核对公式和条件。
2. 公共库选择只检索该库；个人库选择检索公共库加该个人库，绝不扩展到其他个人库。
3. 图谱路径和向量召回共同定位，先做相关性与证据过滤。按资料类型分组召回，减少大量习题挤掉教材的情况。
4. 达到相关性门槛的公共教材优先，其次个人教材、讲义和解析、笔记。类型优先不是事实正确性认证；选择题选项、目录和待分类资料不作为回答依据。
5. 模型生成带逐字证据的结构化解释或推导。后端核对引用原文和前提，再单独请求模型审查支持关系。审查不通过或格式不符则退回有界、完整的原文句子；没有充分证据时明确不足。
6. 正文直接回答，来源在末尾展示文件、页码、片段；计算推导明确标注，不能自动作为判分依据。

审查使用同一已配置模型，不是独立事实引擎，也不是形式化数学证明。不能保证小模型推导、教材OCR和资料本身没有错误。不接外部搜索补全事实。正常改写增加一次模型审查调用；本地模型仍可能较慢。

章节路径与精确条件保存在分块元数据中，不伪造摘要。最多保留4段、600字前提；超出预算或缺失上下文时标记不完整而不是默默删掉前提。新分块规则作用于后续处理；已有索引可按需用“升级本库分块与索引”，不必为批量分类和权限变更重跑OCR。

## 图谱与成员

图谱写入由后台同步，页面和问答不再同步替换整张图。页面显示同步提示和上次快照；Neo4j不可用或丢失快照时显示有标注的PostgreSQL来源图，并将缺失快照排队重建。默认最多160节点、48步布局，按学科/名称探索，手动展开最多600节点。源数据尚在同步期间，快照可能短暂滞后。

管理员资源页管理公共库；成员页显示个人库数量、原文件占用和配额，不显示个人内容。默认每人5个个人库，配额0至100，仅限制后续新建，降低配额不会删除已有资料。原文件占用是documents.size汇总，不包含历史版本、向量或数据库磁盘使用。

已有配置禁用个人库时，运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-kag.ps1 -EnablePersonal
```

该参数显式将PERSONAL_KB_ENABLED设为true；不修改模型密钥。升级自动执行迁移20，不清空数据卷，不删除教材，也不自动重新发布候选题。
