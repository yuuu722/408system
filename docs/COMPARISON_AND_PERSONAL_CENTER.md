# 比较答疑与个人中心（2026.11.06.2）

## 比较答疑

明确比较对象的请求（例如“比较进程与线程的区别”“TCP和UDP有什么区别”“比较栈与队列的区别”）使用单独的比较结构，模型必须按dimension、left、right、left_facts、right_facts分别给出双方内容与证据编号。每项双方都需要有本轮事实支持，不接受只有“有区别”的空泛句，不接受仅有进程原文支撑线程结论。对明确的用户级/内核级线程和同进程共享条件增加保留检查；语义核验仍需逐行核对主语、条件和结论。

教材关键词补充检索和排序针对比较双方、区别、资源、调度等定位上下文；候选证据过滤不相关比较与教学前言。来源引用仍由服务器绑定原文、页码和版本。通过核验后由程序排成表格，不在正文反复写“根据资料”。无法明确识别双方名称时先要求明确对象，不能猜测；无法构成双方有据的比较时不以杂乱原句冒充完整回答。

这是面向专业概念名称的保守解析，不是任意自然语言比较理解器。名称形态、范围过滤、原文匹配和模型审查仍可能漏检或误判；结构化输出不能证明所有结论正确。不会凭预设维度自动补模型常识。内置真实Ollama可选测试增加进程/线程样例，但云端未获得本机模型权重和用户教材，不宣称真实Qwen或整库准确率验收完成。

## 个人中心

导航“个人中心”及右上角账号入口均可进入。可保存昵称、简介、目标分数、每天学习时间、考试日期（可空）、复习阶段和资料偏好。账号名、邮箱、角色只读；昵称不改变登录凭据。资料保存在现有learning_profiles的JSON数据中，不新增独立用户数据库，不增加手机号或其他无关隐私字段。

新接口GET `/api/v1/exam408/study-summary`只使用认证身份，不允许通过参数指定他人。汇总已提交/未完成测评、未计入题次、题族最近有效作答、正确率、当前已录入目录的覆盖率、分科学情和最近十次测评。题次和去重题族分别命名，不能将重复作答累加成掌握度。AI未确认、撤回或其他未计入结果单独提示；浏览、提问、自评不提高掌握度。少于五个有效题族只提示“样本较少”，这是观察提示，不是经过统计校准的置信区间或成绩预测。未测显示待测而非零分。

个人中心可跳转测评、薄弱点和学习任务。最近测评链接支持恢复对应记录；记录读取失败时不会把它伪装成空数据。个人信息读取失败时禁止保存，避免用默认值覆盖旧资料。此次没有改动密码、登录邮箱、权限或管理员对私人知识库的访问策略。
