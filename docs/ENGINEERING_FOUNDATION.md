## 使用入口

- `/exam408/assets`：个人资源草稿、编辑、删除、JSON 导入、人工核对后发布。支持文字单选题、教材链接/文档、视频链接及起止秒数。编辑发布内容会退回草稿，需重新审核。
- `/exam408/assessment`：目标/日期/时间/偏好问卷，初始诊断、日常练习、新题复测、历史报告与错题。题目来源是本人已发布的资源，最多 12 题，按学科轮流取题。问卷不会凭空生成掌握度；缺题时明确提示。
- `/exam408/tasks`：根据已测薄弱知识点关联已发布资源，兼顾文字/视频偏好，生成最多 10 项任务。完成后可复测；完成标记不增加掌握度。视频时间为定位提示，第三方播放器不保证自动跳转。
- `/exam408/assistant`：历史会话、重命名、删除、刷新恢复、多轮上下文、流式回答、取消与中断提示、打开引用文档。
- `/exam408/resources`：TXT/PDF/DOCX、处理进度、失败重试、查看原文。

## 学情与数据契约

单选题用 `PointID` 关联已有知识点，`Payload.Answer` 为从 0 开始的序号，`-1` 表示待核对。发布时检查题干、选项、答案、解析和来源；教材需文档或 URL，视频需 URL。下载空白 JSON 模板后填写即可导入草稿，导入不是一批原子事务，失败会报告已成功条数。

资源仅本人可见，当前“审核”是本人确认，不是管理员审批或教师复核系统。每次修改增加版本，测评保存当时题目快照。未交卷的试题接口不返回答案解析；后端判分，重复提交返回原报告，不重复记分。未提交作答选项尚未自动保存，可恢复试卷后重新选择。

雷达图按每道不同题目最近一次作答结果统计准确率，未测科目为 null/待测；仅四科都有结果时连接完整多边形。知识点掌握度也按不同题目最近结果计算，置信度为题量的规则值。浏览、提问、任务完成只记录行为，不能证明掌握。旧数据库的历史规则分数不会自动清空，旧看板可能保留历史值；本次新雷达仅统计结构化测评事件。

推荐为规则匹配，不是训练模型、诊断量表或自适应测评；目标分数、学习时长目前仅保存，未用于排课。难度字段已保存，但尚未实现难度校准和分层选题。重复旧题可练习，但新题复测排除已交卷题目。

## 文档任务与问答

迁移 `000005` 增加任务、会话顺序、资源、问卷、测评和任务表。API 入队，独立 `APP_ROLE=worker` 进程执行。数据库行锁避免同一任务并发领取；崩溃释放锁后可重新处理，分块整体替换防止重复入库。这是从头重跑，不是逐阶段断点续传；每次处理最长 10 分钟，暂时网络/限流/服务端错误最多尝试 3 次，解析错误需人工处理后重试。每个在途任务占一个长事务连接，尚未进行规模/负载验收。

PDF 按物理页提取并分块，引用携带页序号，原文件访问有所有权校验。DOCX 提取文字，不保证原书页码；TXT 要求 UTF-8。有效正文采用字符数量/多样性门槛，能够拒绝空内容、部分水印页；前两页和末页允许跳过，内部疑似无正文页提示 OCR/检查。这不是 OCR，也不是可靠的水印识别器，图表页可能误拒绝，必须抽查解析结果。

会话按用户与知识库隔离，最近 10 条消息/最多 8000 字上下文；短追问采用简单规则附加上次问题辅助检索。历史列表最多 100 会话，每个返回最近 200 消息。新回答成功后原子保存问答对，失败/取消的部分回答不作为完成消息保存。上游使用 SSE，要求完成标记；前端和 Nginx 支持流式。没有足够相关证据则拒答。原文链接打开整个 PDF 并携带页序号，不是关键词高亮。

## 可复跑验收

在项目根目录运行独立性检查：

```powershell
node scripts/check-independence.mjs
```

在 `backend` 目录运行：

```powershell
$env:TEST_DATABASE_URL='postgres://exam408:exam408@localhost:5432/exam408?sslmode=disable'
& 'C:\Program Files\Go\bin\go.exe' test -count=1 ./...
& 'C:\Program Files\Go\bin\go.exe' vet ./...
```

该连接仅用于新建随机命名测试数据库，测试结束删除该测试库；需建库权限。不设置环境变量时 PostgreSQL 集成测试会跳过，不能据此宣称数据库验收通过。

覆盖草稿发布、快照隔离、答案隐藏、幂等提交、跨用户隔离、任务生成、复测排除、任务取消/恢复/并发领取、合成 TXT 处理、会话与 SSE 协议。`internal/service/testdata/synthetic_relevance.json` 是固定合成词面相关性回归集，包含单汉字关键词与同义表达拒答的已知边界，不是实际教材检索质量评测。DOCX 由测试即时生成，模型由本地模拟服务代替。

前端运行 `npm run build`、`node --test --test-isolation=none tests/*.test.mjs`。Compose 当前包含 backend、worker、frontend、postgres、redis；本地嵌入服务仍需按其 README 单独启动。新增 worker 需要与 API 使用相同上传卷和模型配置。
