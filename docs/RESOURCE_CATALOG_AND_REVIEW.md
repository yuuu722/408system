# 资料分类与题库审核

一份原文件存储一次，管理员在“公共资料管理”选择用途：

- 知识库：用于检索与来源引用，不自动抽取题目。
- 题库：抽取候选题，不作为智能答疑的检索资料。
- 两者：用于检索，同时抽取候选题。答疑仍须通过证据筛选，不能直接采信未解析选项。

PDF/Word/文本文件在资料管理上传；已结构化题目可在“题库与课程审核”导入 JSON。上传不会把题目直接发布为可测评题。

## 整理已经上传的文件

1. 管理员进入公共资料管理，选择目标知识库，点击“整理本库已有资料”。页面显示逐文件进度和失败详情，只处理已就绪文件。它复用数据库保存的解析结果，不重新上传或运行 OCR，不重建向量。
2. 文件名规则建议类型与四科学科；无法确定的明确标记“待分类”或“待确认学科”，跨科资料由管理员选择“综合 / 跨科”。建议不是人工确认。考纲单列，习题/做题本与教材区分。
3. 使用“分类与用途”修正并确认。首次整理旧文件时，明确识别的习题/真题建议题库用途，其余默认知识库；明确选择过的用途及已确认分类不被批量建议覆盖。新上传文件以上传时选择的用途为准。
4. 需要抽题的文件设为“题库”或“两者”，再整理。知识库用途不抽题，对应历史自动候选不混入题库列表。切换为仅知识库会将该文件自动抽取题目撤回待审核，保留内容和历史测评快照。
5. 在“题库与课程审核”的待审核区查看题干、选项、原文及问题提示。补齐知识点、可靠答案和来源，核对图片/公式，选择“已核对…发布”并保存。仍有完整性错误或无可靠答案时不会成为可测评题。

管理员可筛选已可用和待完善资源，以及未关联知识点；学生列表只显示可用资源。缺少来源答案不会用 AI 猜测后自动批准。

## 现有数据升级

迁移17将此前自动抽取、尚无审核标记的公共题目保留为待审核，不删除文件、账号、教材、人工资源或历史测评。原来的题目内容/解析错误仍需管理员核对；仅修正状态文字不会修复 OCR。

重复整理按稳定抽取标识更新候选题，保留同标识已发布题目的人工修订；题目内容变化导致抽取标识变化时按新候选处理。处理中文档拒绝整理，重建题目时校验活动文档版本，避免旧页面覆盖新版本。

分类仅使用文件名/已有类别规则，不是训练模型；抽题仍限编号单选题，不具备通用整本试卷自动还原、跨文件自动匹配答案或公式/图形正确性验证。未明确的项目保留待核对，不能批量伪造知识点、答案或难度。
