# 知识点复习单元（2026.11.09.1）

今日计划由“逐道题目列表”改为知识点学习单元，每个单元展示学习目标、推荐原因、今日预计用时、完整单元预计用时及四步进度。

1. 知识复习：按知识点名称定位有权限访问的教材，教材优先于补充材料。展示教材摘录、来源与原文阅读入口，也可进入教材问答请老师解释定义、条件和关系。没有教材时明确待补充，不由程序填入常识。
2. 例题：从同知识点的可用资料答案题中选择一个未被本单元用作独立练习的题族，显示题目、原文答案解析及老师讲解入口。目前为资料题选例，尚非专家标定的典型题体系；不声称所有原题解析均已人工复核。
3. 独立练习：使用安排到该单元的另一题族，单元接口隐藏答案与解析；提交后查看原文反馈。只在本日计划建立后的有效作答才算本单元练习进度，不把旧前测结果直接算作完成。
4. 新题检查：排除当前例题、练习、以前在本系统显示过的单元例题与测评题族，另选有资料答案的新题；未提交的检查可以继续。没有新题明确提示，不拿例题充当复测。完成检查若仍有错误提示补学，完成流程不等于掌握。

## 计划和进度

- 保留有效作答、重要性、复习间隔的现有规则排序；先给各知识点一个学习时段，再安排第二道练习，每个点最多两个计划资源，避免单个知识点的题目塞满整日。
- 首个资源的预计时间计入20分钟知识/例题/检查开销；题少时为例题和新题保留题族。时间为估计值，不是实际学习时长。
- 预算不足以完成整单元时明确分次完成。当天已安排的单元保持稳定，不在每次提交后换题；减少预算时以已经安排的时间为下限，次日新计划按个人中心预算安排。
- 阅读与例题由用户确认，按用户、知识点、资源版本存储；资料发生变化需重新核对。练习和检查进度来自真实有效作答，不能用阅读按钮伪造。全部四步完成后再记录旧任务为完成，不直接增加掌握度。
- 旧的题目式计划在已前测用户进入计划时升级，或点击更新计划升级。保留既有成绩、已完成任务和资料。

## 验证边界

通过隔离PostgreSQL与HTTP集成测试核对教材权限、阅读保存、例题和练习分离、练习答案隐藏、提交更新、新题排除、复测恢复、错题提示、预算及旧成绩不冒充完成；浏览器回归验证合并导航与单元展示/例题展开/题目跳转/异常提示/响应式布局。模型讲解沿用现有有来源的答疑服务；没有用用户本地千问或真实上传资料作本轮验收。
