# 当前功能与实现边界

校准日期：2026-10-19。本文描述当前代码具备的能力；安装、操作和逐文件函数索引见 [使用与代码指南](USER_AND_CODE_GUIDE.md)。历史测试结果不等于真实教材或教学效果验收。

## 1. 系统定位

面向学生个人的 408 学习助手，主要流程为：直接浏览公共课程 → 公共资料答疑与测评 → 查看薄弱点和每日计划；可选择上传个人资料补充检索。四科内置 12 个目录、38 个基础主题和配套讲解、例题、原创练习，尚不是完整官方考纲或完整教材。详见 [公共课程与图谱](PUBLIC_KB_ADMIN_ROADMAP.md)。

## 3. 学情与计划的准确口径

- 资料答案或个人提供的答案可用于判分；AI 参考答案默认不计入学情。用户确认是自评结果，不能当成标准考试测量。
- 同题及显式变式归入题族，以最近有效作答统计；确认、改判和撤回会替换本次贡献并重算，保留修改账本。旧报告晚确认不会覆盖更新作答。
- 阅读、提问、任务完成不能直接证明掌握，不直接加分。
- 每日计划按北京时间划分日期；当天首次生成冻结预算，之后修改问卷预算次日生效。重复生成在剩余预算内补充并保留完成状态，最多 20 项；没有可用资源可返回空计划。
- 答错可立即补练，连续有效答对采用 1/3/7/14/30 天规则间隔。预计分钟数来自视频片段、用户填写或默认估计。
- 难度、掌握度和复习策略均为可解释规则，不是 FSRS、BKT、IRT、深度知识追踪或已训练模型。

## 4. 文档处理与引用的边界

- PDF 按页保存检查点；DOCX 每 16 个正文节点为逻辑段，不能声称对应 Word 物理页。不是上传网络断点续传。
- 每次任务最长 30 分钟；暂时故障最多自动尝试 3 次。已提交页和每批 4 个向量可恢复；未提交工作可能重算。
- 重处理期间保留旧活动版本供检索，但仅使用当前嵌入空间兼容的数据；首次处理未完成时没有可检索版本。
- 百分比是阶段权重：解析约 5%–15%、向量化约 20%–90%。长 PDF 逐页运行 CPU OCR 时会长时间停在低百分比，不是耗时预测。
- 自动抽题只覆盖常见单选题结构；跨题图片是页面级关联，复杂试卷和跨页答案仍需抽样核对。
- PDF 高亮对应检索内容块，不是逐字或单句对齐，也不能证明模型回答正确。裁切页、旋转基准不一致或旧资料无映射时降级为页级/文本定位。
- DOCX 原生 OMML 公式尚未转换，建议导出 PDF；表格内图片没有精确恢复单元格图文排版。
- 完整解析快照上限 64 MiB；历史版本和检查点尚无自动淘汰策略。超长教材建议拆章，真实 OCR 性能和存储增长仍待评测。

## 5. 模型与费用

| 操作 | 当前方案 | 云端大模型额度 |
|---|---|---|
| OCR、版面、表格、公式解析 | 本地 PaddleOCR PP-StructureV3，CPU | 不消耗 |
| 本地向量化 | text2vec，768 维，CPU | 不消耗；改云端嵌入后按供应商计费 |
| AI 答疑、参考解析、生成练习 | 配置的文本模型 API | 可能消耗 |
| 图意理解/图像辅助判分 | 可选 `VISION_*` | 配置并实际调用时可能消耗；当前未配置 |

`AI_DEMO_MODE=true` 为显式演示向量与片段预览，不是本地 text2vec，也不是真实 AI 回答。默认正常模式缺少必要模型配置时不提供 AI 答疑。生成练习每人滚动 24 小时最多 5 次请求，失败也计次数；幂等请求复用完成结果。
