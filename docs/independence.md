# 408 Assistant 独立开发边界

校准：2026-10-15。当前产品和限制以 [CURRENT_FEATURES.md](CURRENT_FEATURES.md) 为准；通用开源依赖不属于项目自研贡献。当前已实现 OCR 服务适配、版本/租约/检查点、来源阅读器、题族与确认账本、每日规则计划和显式练习生成。未训练或接入 FSRS/BKT/IRT/深度知识追踪，未接入 AgentArts/自主 Agent，真实视觉模型仍未配置。

## 项目策略

WeKnora 仅用于架构、工程组织、RAG 实现思路和知识库流程参考。不直接 Fork，不复制整个模块，不复用其品牌、页面 UI 或 Logo，不作为构建、测试、部署或运行依赖。开发者可阅读参考源码，但交付物不需要该目录存在。

408 Assistant 自行维护前端、后端、数据库结构、API、知识库、知识图谱、学习模型、推荐算法、Agent 和部署体系。这里的“独立”是业务实现和交付边界独立，不意味着自行实现 Vue、数据库、容器平台或基础大模型。通用开源依赖仍保留，不能把这些依赖包装为本项目原创贡献。

## 实现归属与完成状态

| 能力 | 本项目维护的实现 | 当前边界 |
|---|---|---|
| 前端 | `frontend/src`：学习主页、知识体系、资料、问答、薄弱点、设置 | 自有页面组合与样式；使用 Vue、Pinia、TDesign 通用组件，不使用 WeKnora 页面和品牌资产 |
| 后端与 API | `backend/cmd/api`、`internal/httpapi`、`internal/domain` | 本项目 Go 服务及 `/api/v1` 契约 |
| 数据库 | `backend/migrations`、`internal/repository` | 自有迁移、用户数据范围、408 业务表；使用 PostgreSQL/pgvector 基础设施 |
| 知识库与 RAG | `internal/service/document.go`、`providers.go`、`rag.go` | 自有文档处理、向量检索与引用回答流程；真实模型由外部服务提供，生产质量尚需验收 |
| 知识图谱 | 教学知识点关系、语义实体关系表、资料映射 | 部分结构、关键词检测及映射已实现；自动抽取、图查询、可视化闭环未完成 |
| 学习模型 | `internal/service/learning.go` | 按题族最近有效作答与可撤回确认计算掌握度；不是训练模型 |
| 推荐算法 | `internal/service/learning.go` | 统一每日预算、复习间隔和资源偏好的可解释规则计划；尚无教学效果证明 |
| Agent | 规划由本项目维护工具契约、执行状态、权限和评测 | 尚未实现；当前 AI 助手是固定 RAG 流程，不能称为自主 Agent |
| 部署 | `compose.yaml`、两端 Dockerfile、`frontend/nginx.conf` | 独立部署、持久化任务和检查点恢复已实现；服务器 TLS、监控及实际备份恢复演练仍待完善 |

## 设计与贡献留痕

新增能力先定义 408 用户场景、输入输出、数据归属和验收方式，再独立实现。参考记录写入 `weknora-reference.md`，说明“参考思想、自己的实现位置、未采用部分”。不要通过重命名直接搬运模块，也不要删除真实的第三方来源记录来证明独立。

项目亮点应由可复现结果支持：考纲覆盖、学习事件可信性、掌握度评估、推荐效果、资料引用正确性。通用分层架构或固定加权公式本身不构成已验证的算法创新。

## 可执行检查及局限

在项目根目录执行：

```powershell
node scripts/check-independence.mjs
```

检查覆盖前后端源码、依赖清单、前端文本资产、Dockerfile、根目录 Compose 和环境模板中的显式 WeKnora 引用；检查跳过构建产物、依赖目录、上传存储和真实 `.env`，不需要参考仓库。已接入 `frontend` 的 `npm test` 和根目录 `make test`。

2026-09-28 验证：独立性脚本扫描 48 个文件通过，`npm --prefix frontend test` 中独立性检查及 2 项现有路由测试通过，脚本语法检查通过。人工审阅未发现依赖清单或 Compose 中的 WeKnora 依赖，前端源码中未发现其品牌引用。此结论不是历史来源证明，也不是整库代码相似性或页面视觉相似性鉴定。脚本不能识别重命名后的复制代码或图片内容；新增代码和资产仍需要审阅。当前已知的空知识库页面缺陷也不因该检查通过而得到修复。
