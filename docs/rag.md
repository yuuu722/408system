# 当前文档检索与 RAG

校准：2026-10-15。完整入口和操作见 [功能清单](CURRENT_FEATURES.md) 与 [使用指南](USER_AND_CODE_GUIDE.md)。

## 入库与检索

支持 TXT/Markdown/PDF/DOCX。文本走本地解析；配置 DOCUMENT_PARSER_URL 时 PDF/DOCX 走独立分页结构服务，复杂页使用本地 PaddleOCR。分块以页面/逻辑段为边界，常规窗口约 900 个 Unicode 码点、重叠 120；规范文本与来源块位置一起保存。

API 保存源文件并入队，独立 worker 处理版本与检查点，完整解析、分块和向量验证后原子启用。重处理期间旧活动版可用；模型空间不兼容时不会混用旧向量。检查点不是上传断点续传。

当前可使用本地 text2vec 768 维或兼容 /embeddings 的云端服务。空间标识包含端点、模型、维度和演示模式；维度/空间筛选在余弦距离计算之前完成。当前使用精确检索，旧 HNSW 索引已移除，不宣称大规模性能达标。同名模型更换权重需改版本标识。

## 回答与历史

POST /api/v1/exam408/assistant/chat 提供同步问答；POST /api/v1/exam408/assistant/stream 提供 SSE。前端使用流式入口，支持历史、追问、取消、会话改名/删除；保留最近有限上下文，短追问仅通过简单规则补充上次问题。

检索结果需通过 RAG_MIN_SCORE（默认 0.35）和保守词面重合过滤；证据不足拒答，可能拒绝同义表达。通过后组织编号证据、调用模型，成功完整问答对经 SaveTurn 原子保存；失败/取消的部分结果不作为完整消息入库。状态接口只公开模式和配置是否齐全，不等于供应商健康测试。

引用含文档、片段、页/段、RevisionID、Regions、LocationQuality。PDF 阅读器显示原页和证据区域；TXT/Markdown/DOCX 提供解析文本定位。裁切、旋转不一致、旧文档无映射等情况降级，不是逐字高亮。Markdown、表格和公式由通用前端库安全渲染。

## 模式与能力边界

AI_DEMO_MODE=false 为正常模式，答疑需要 LLM 和 Embedding 配置。缺 Key 不会静默回退。true 显式选择确定性演示向量/片段预览，不调用外部回答或嵌入模型，不能证明真实语义检索效果。

图像 RAG 使用可选 VISION_*，当前留空；OCR 不等于图意理解。真实教材检索评测、混合检索/BM25、reranker、专门提示注入分类器尚未完成。新增流程通过合成/替身工程验收不等于真实供应商或教材质量验收。
