# 薄弱点复习与知识导航（2026.11.09.2）

## 薄弱点复习

从“分数排序＋建议文字”改为“复查依据＋可执行学习内容”。左侧显示最近独立题组的有效错题数、样本数量、学科和参考重要性；待确认疑问单列，不把提问当错题，不把待测视为薄弱。无错题时建议诊断，不宣称全部掌握。

右侧按当前点及其下级范围提供：

- 最近有效错题、题干选项、历史解析及完整报告。按题族最近有效作答替换旧记录，后来答对的旧错题不持续挂在列表；用户确认或AI辅助判断标注来源性质。
- 教材摘录、页码与原文阅读。使用可访问教材，支持中文空白差异、目录关键词及有限下级概念定位；含TCP等缩写的目录名要求匹配协议名，避免仅因“可靠传输”抓来HDLC段落。
- 当页老师讲解、风格选择、中文朗读和来源。默认选取实际教材所在的可访问知识库，可切换资料范围；无需先安排进日计划或先拥有本点题目。讲解沿用来源核验的RAG接口，不是外部常识补齐；模型失败保留教材和原文解析。
- 资料参考例题及解析、老师逐步讲例题入口，和不同题组的独立练习。练习接口隐藏答案解析；已在例题或测评出现的题族不充当新练习。原题典型性与全部OCR未作专家认证。
- 进入日复习单元/随堂教学/题库等后续入口。

## 思维导图的用途

展示408知识目录，帮助定位当前知识点属于哪一科、哪一章节，进一步选择下级概念，再进入上述完整学习内容。目录父子关系不是因果或前置知识证明；知识关系图谱仍为另一视图。

新增“本点题组”和“含下级题组”区分，避免章节父节点由于没有直接挂题而被显示成空内容。目录描述仍标为范围说明，不冒充教材定义。搜索支持名称与编码，选中状态和URL保持一致，手机选择后滚动到详情。重要性和机构来源放在可展开依据里，不虚构考频。

## 边界与更新

资料确实缺少时显示缺项；没有教材不凭模型记忆编课程，没有可靠答案不填假练习。模型讲解按点击生成，不批量给所有节点预生成未经核验的定义。没有额外解析上传资料，也不自动修改历史成绩。

新增知识点学习内容接口，复用迁移27的题族曝光记录，未新增数据迁移。需要同时更新backend/worker/frontend至2026.11.09.2；无需重新上传、重新解析或重做前测。

验证：隔离PostgreSQL＋HTTP测试核对父子覆盖、私有教材隔离、空白匹配、TCP/HDLC相关性、错题更新和答案隐藏；浏览器合成接口测试核对当页讲解朗读、模型错误保留教材、旧点响应不覆盖新点及320–1440宽度布局。未在用户本地Ollama或全量上传资料上验收。
