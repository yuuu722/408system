# 408 学习与老师功能（始于2026.11.07.7，2026.11.08.1调整入口）

更新后进入“学习任务 → 老师与学习方案”（`/exam408/tasks?tab=teacher`，旧`/exam408/learning`自动跳转）。普通用户尚无已提交前测时先进入“测评学情”；可浏览其他学习入口，不阻断资料访问。管理员有“学习任务体验”入口，考频来源编辑在“知识体系 → 思维导图 → 知识点详情”。更新运行 `scripts/start-kag.ps1` 即可自动迁移数据库，不需要再次OCR或重新上传资料。

## 学习流程

1. 前测：只选当前可用且有资料答案的单选题，最多48题。优先不同知识点，再轮换四科；同题家族不重复，不让未核验AI变式进入初始判分。页面展示每科可测及已测知识点数量；缺题科目/知识点保持待测，不能声称覆盖所有考纲细节。旧的日常练习和复测仍保留。
2. 学情：按题族最近有效作答统计，少于3个独立题组保持样本不足或“待复查（有错题）”，不下全面能力结论；至少3题且正确率低于60%提示需要补强。只是可解释的规则反馈，不是训练好的能力/IRT模型。
3. 学习方案：按原复习规则，再结合知识点重要性、有效错误/正确情况和待确认疑问排序，遵守个人每日时间预算；作答后刷新尚未完成任务，已完成记录保留。同题历史别名用于避免副本抬高独立样本数。
4. 老师课堂：选择知识点、资料范围和风格，先用现有教材检索及来源核验生成一个小节，再显示该知识点一题并等待作答；优先有解析的真题类来源，不宣称所有题都已人工标定为典型题。未提交不能获取老师详解，也不会自动跳下一节。
5. 反馈：由存储的资料答案判分。老师针对本次选择，使用存储的原题条件与已审核解析重新组织讲解；条件作为必须保留的前提，核验通过才展示及缓存。讲解不改变分数。模型失败、公式疑似损坏、原文解析不足时明确保留原文解析，不能把它冒称模型讲解。
6. 记忆：保存账号自己的目标、偏好、待确认疑问，可修改、标记解决、删除。正常问答中明确的疑问/如何/比较等问题按目录关键词记为待确认信号，不直接计成错误，不降低掌握度。教学背景使用复习阶段和少量未解决的目标/偏好，作为不可信自述，不充当知识证据或执行指令。管理员不能通过这些接口读取其他用户记忆或课堂。

## 风格和语音

默认“轻松鼓励”，另有“循序引导”“重点直讲”。风格由受控选项决定，不提供冒充真实教师的身份/声音。语音使用浏览器SpeechSynthesis，用户点击后朗读，可停止、选择设备可用的中文音色；不新增付费TTS接口。不同设备音色、数学符号朗读效果不同；没有中文音色时展示说明，不承诺真人克隆或专业数学语音。该功能不会把语音传给外部TTS服务。

## 思维导图、重要性与考频

新增按四科目录逐级展开的思维导图，点击节点查看定义、学情、可练习题组数、参考重要性及出处，跳转专项练习、题库、答疑和关系图。沿用已有知识点ID和题目关联；修正继承目录中“排序在图下面”“应用层在传输层下面”两处归类，不改题目/成绩。

关系图只对已关联规范知识点的节点叠加参考重要性和年度覆盖。这里的重要性是显式排序政策，分为：

- 相同年份区间、同一统计分母的至少两家机构报告，使用“涉及该知识点的年度比例”均值；不同口径保持单列。优先最近可比区间，再选较多统计年度。列出机构、区间、分子/分母、标题、链接、摘录，显示需核对原文；不保证机构报告本身正确或独立。
- 尚无可比机构报告时，使用本库已就绪公共真题中可明确识别的同学科年度覆盖。排除标题为模拟/风格的卷子，不把重复副本当多次命题，不把未知年份计进去。只是库内样本，不是完整历年统计，更不是预测概率。
- 仍无数据时用目录基线，不伪造考频；知识点未测也不等于薄弱。

机构统计由管理员在知识体系的思维导图知识点详情录入或通过 `POST /api/v1/admin/frequency-sources` 提交，只接受HTTPS来源、摘录及一致的年度分子分母。保存是格式校验，非自动联网背书。目前尝试访问王道、新东方考研、文都及研招资讯公开站点均被云环境网络代理403阻断，因此没有导入虚构机构报告，也没有声称已完成机构事实核验。该部分仍需在可访问网络下核验真实公开报告后补入。

## 实现和验证范围

新增PostgreSQL表：learner_memories、point_frequency_sources、coaching_sessions；任务增加superseded标记，以便重新安排未完成任务并保留已完成记录。老师讲解仍使用既有模型和证据核验路径，没有切换模型、重建向量或要求重跑文档解析；图谱仍保存在原Neo4j/兼容存储，统计字段在读取时叠加。

测试覆盖四科/知识点轮换、同题去重、未核验AI排除、学生数据隔离、记忆不改变掌握度、不同机构统计口径隔离、作答前隐藏答案和拒绝详解、重复提交不重复计分、受控模型走完整RAG及老师详解原文核验、缓存恢复、讲解不改成绩、损坏公式拒绝。浏览器验收验证新用户引导、记忆保存后刷新仍存在、无脚本错误及390px无横向溢出；没有替代真实用户教材和本机Qwen的全量教学质量验收。开放式主观题自动评分、经过标定的题目难度与严格能力测量仍未实现。
