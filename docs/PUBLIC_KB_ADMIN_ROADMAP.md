# 公共 408 课程、权限、检索与图谱

更新：2026-10-19。本页描述当前实现和复现步骤。

## 新用户不需要先上传

迁移 14 自动建立系统公共库（升级时优先复用已有公共库），并建立四科 12 个目录、38 个课程主题、38 份讲解与例题、38 道带参考答案和解析的原创基础练习。公共库属于系统维护的共享语料，不属于新注册用户的上传空间。

这些内容覆盖数据结构、组成原理、操作系统和网络的基础章节，定位为可运行的基础课程，不是官方逐年考纲全文、完整教材、历年真题库或教学效果保证。管理员可继续扩充目录、讲义、试题和真实授权教材。

用户注册后可直接进入“知识体系”阅读讲解与例题，在“公共与个人学习资源”浏览资源，在“测评”参加诊断和练习，在每日计划中使用公共学习资源。公共题目答案在测评交卷前从测评响应中隐藏；课程练习的参考答案可以在学习资源中查看。

API/worker 启动时把内置讲义物化到 `STORAGE_ROOT` 并持久化文档任务；worker 通过同一套解析、分块、嵌入、活动版本和来源引用流程建立索引。重复启动不会复制讲义文档。初次索引完成前，课程阅读和测评仍然可用，答疑语料需要等待 worker 完成。请保留上传存储卷。

## 管理员与普通用户

注册身份固定为 `student`，不能通过请求指定管理员。首个管理员仍通过独立的一次性 `ADMIN_BOOTSTRAP_TOKEN` 初始化：

1. 注册用于管理的真实账号。
2. 在服务环境安全设置至少 32 字符的随机 `ADMIN_BOOTSTRAP_TOKEN`，重启 API。
3. 调用 `POST /api/v1/admin/bootstrap`，JSON 为 `{"Email":"管理员邮箱","Token":"部署者设置的令牌"}`。
4. 成功后移除令牌并重启 API。已有真人管理员时，初始化接口返回 409。

系统服务身份拥有锁定的密码散列，不能登录，也不阻碍首个真人管理员初始化；没有内置通用管理员密码。公共库已由系统初始化，不需要等管理员上传才能出现。

公共资源读取面向所有登录用户；普通用户不能修改公共课程、公共文档、图谱来源映射或目录。管理员可以维护公共资源，包括其他管理员上传的公共文件；任何角色都不能读取其他用户的私有资料。系统公共库不通过普通知识库删除接口移除。

管理员可在知识体系详情中维护目录名称和说明，使用 `POST /api/v1/admin/knowledge-points` 增加规范知识点，使用 `PUT /api/v1/admin/knowledge-points/{id}` 修改名称、说明和关键词（编辑时保留代码及父级身份）。新增请求包含 `SubjectID`、可选 `ParentID`、`Code`、`Name`、`Description`、`Keywords`、`Level`、`SortOrder`。目录变更同步到公共基础图谱；讲义是单独维护的学习内容。

“公共与个人学习资源”中管理员可新建公共资源并编辑已有内容。内联公共讲义保存后会重新进入文档索引队列；修改公共试题不会修改用户已提交测评的题目快照。需新增其他管理员时应采用部署者审核的账号管理流程；当前未提供任意提权入口。

## 答疑检索范围

`POST /api/v1/exam408/assistant/chat` 与流式 `/assistant/stream` 接受 `KnowledgeBaseID`、可选 `ConversationID`、`Question` 和 `IncludePersonal`。

- 默认 `IncludePersonal=false`：检索公共资料。
- 选择自己的个人库并设置 `IncludePersonal=true`：优先采用相关的公共证据，再补充所选个人库的证据。
- 选择公共库时，不会隐式搜索任何个人库。
- 私有库访问校验、活动文档版本和嵌入空间/维度过滤始终生效；无充分证据时不生成虚构引用。

前端有对应的个人检索勾选项。引用可查看原文；公共文档的原文与结构读取也受登录校验。API/worker 须使用相同的模型配置；更换嵌入模型或维度后，需按已有重处理接口刷新文档索引。

## 图谱自动构建与证据

系统先以管理员维护的课程目录和关系建立共享基础图谱，无需上传就有节点与基础关系。文档激活时匹配规范知识点、建立资料关联，并为匹配结果保留原文块。

默认关闭模型抽取。设置 `GRAPH_EXTRACTION_ENABLED=true`，同时配置正常模型模式的 `LLM_*`，处理资料时可调用模型提出候选实体与关系，可能产生模型费用。`AI_DEMO_MODE=true` 不调用模型抽取。

候选不会直接写为权威考纲：仅接受允许的实体/关系类型、0.75–1 的置信度、精确出现在同一资料块中的 12–300 字证据，且关系证据本身须包含两个端点名称。规范知识点代码解析为目录实体；新的实体必须独立通过证据校验；反向冲突的规范先修关系被拒绝。模型失败不使已完成的资料索引失效。

图谱页区分目录与 AI 候选，显示节点、关系、原文依据和来源文档。公共图谱按公共库复用节点；重复处理不会复制同名同类型节点。不同来源的证据可以有多条关系记录。个人上传只补充个人图谱，不能修改公共图谱。候选节点不是已经人工审核的新考纲；目前没有独立的人工候选审批工作流。

修复了此前正常禁用图谱模型时将 nil 指针装入接口、导致文档已显示 ready 后 worker 崩溃的问题。

## 验证

在有 PostgreSQL/pgvector 的开发环境中：

```bash
node scripts/check-independence.mjs
cd backend
# TEST_DATABASE_URL 指向可创建隔离测试库的开发 PostgreSQL；不要填写生产连接。
go test -count=1 ./...
go vet ./...
cd ../frontend
npm ci
npm test
npm run build
```

`TestPublicCurriculumEndToEnd` 需要 `TEST_DATABASE_URL`，自动创建并删除随机隔离数据库。它验证：重复迁移与初始化、新用户免上传学习和测评、计划、首个管理员初始化、公共写入限制、公共讲义索引与更新、带公共引用答疑、文档原文读取、个人检索开关、跨用户隔离、自动节点/关系/证据、虚构候选拒绝和重复处理去重。

模型采用确定性替身，数据库、HTTP、文本解析、文档任务和索引是真实执行；这不是对某个真实 LLM、真实嵌入模型或 OCR 效果的验收。浏览器人工验收、压力测试与真实模型效果需要分别记录。
